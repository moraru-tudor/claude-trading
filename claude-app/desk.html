Connect this page to your desk

  1. On your computer, in the claude-trading folder, start the bot: npm run paper (or npm run live).
  2. In the Claude desktop app, add the trading-desk local server to claude_desktop_config.json (the README has the exact lines) and restart the app.
  3. Open this page in the Claude desktop app and allow trading-desk when asked.

Your Phantom key stays in the bot's .env on your computer. This page only reads the numbers and can pause the desk.
